# Passe — frontend

Interface em Next.js, React, Tailwind CSS e shadcn/ui. O passo a passo completo está no [README da raiz](../README.md).

Atalhos, dentro de `frontend/`:

```bash
cp .env.example .env.local   # API_URL = origem da API, sem /api/v1
npm ci
npm run dev                  # http://localhost:3001
npm run lint
npm run format:check
npm run build
```
